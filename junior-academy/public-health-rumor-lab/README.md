# مختبر الشائعات الصحية — Junior Academy

مشروع تعليمي في **الصحة العامة**: أي حد يلصق شائعة، المختبر يفحصها فوراً ويصنّفها شائعة / معلومة مدعومة / غير كافٍ.

هذا **مش وكيل ذكاء اصطناعي**. المحرّك حتمي: مطابقة نغرام + كلمات مفتاحية + أنماط ضرر، فوق قاعدة معرفة بروابط WHO.

## تشغيل المحرك والاختبارات

```
python tests/test_engine.py -v
```

لتشغيل التطبيق الكامل والواجهة الحديثة، استخدم من مجلد المشروع الأب:

```
py agent/server.py
```

ثم افتح `http://127.0.0.1:8733/`.

## حدود

تعليمي فقط. ليس تشخيصاً. لو التطابق ضعيف، النظام يمتنع بدل ما يخمن.
